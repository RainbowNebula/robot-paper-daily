CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators Kechen Liu 📄 PDF
🧠 AlphaXiv		 -
📋【论文的motivation是什么】 1. 现有 action-conditioned video world models 基本被单一 robot embodiment 绑定，无法利用 internet-scale heterogenous video data 学习更通用的 physical priors。 2. 不同 embodiment 的 action space 差异巨大，human videos 又通常没有 action labels，导致 cross-embodiment video learning 很难直接做。 3. 机器人世界模型的物理一致性不足，限制了 zero-shot physical simulation 和对真实 manipulation policy 的反哺。 4. 研究一个更统一的框架：能否像 LLM 一样通过跨形态数据规模化，学到与 embodiment 无关的 generalizable physics。 【前人的工作如何解决该问题，存在哪些空白】 1. 以往 video world models 主要在单一机器人上训练，避免了 action space mismatch，但代价是完全放弃了跨形态大规模视频数据，泛化上限很低。 2. 一些方法使用 end-effector actions 或 language instructions 对齐行为，但这类表示要么无法覆盖无标注 human video，要么无法直接 zero-shot 部署到真实机器人。 3. latent action learning 能吃进无标注视频，但学到的 action 往往缺乏可执行性，难以直接作为 real-world control interface。 4. 过去缺少一个同时兼容 human/robot、多种 action conditioning、并能从跨 embodiment 数据中稳定提炼 physics priors 的训练范式。 【提出了什么创新的方法】 CLAP 的核心流程是：先把不同 embodiment 的动作表示统一到一个跨形态训练框架里，使用 end-effector poses、natural language instructions 和 learned latent actions 三种 conditioning 形式共同覆盖不同数据源；然后采用 curriculum-based cross-embodiment learning，先在大量 unlabeled video 上用 latent actions 学习基础物理规律，再迁移到 end-effector action space 中做 zero-shot 可执行建模；最后再把这种 cross-embodiment model few-shot adapt 到目标机器人 embodiment，得到更高保真、单一平台专用的 video world model。进一步地，CLAP 还能在 inference-time 做 cross-policy planning，并结合 RL finetuning，把 world model 直接用于提升真实 manipulation policy 的表现。
